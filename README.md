# Coffee Shop Sales Analysis

##  Project Overview

This project focuses on analyzing retail sales data for a Coffee Shop using Excel. The goal is to extract actionable insights from historical data that can improve operational and marketing decisions.

We explore trends across time, locations, and product categories to answer key business questions such as:

- When do customers buy the most?
- Which products and categories generate the highest revenue?
- How does performance differ across store locations?

## Objectives

- Analyze sales trends by **day of the week** and **hour of the day**
- Identify **peak sales periods**
- Calculate **monthly sales revenue**
- Compare **sales performance across different store locations**
- Find the **average order value per customer**
- Determine **top-performing products** by quantity sold and revenue
- Break down sales by **product category and type**

## Key Insights (with visualizations)

This project includes:
- Pivot tables for trend and category breakdowns  
- Charts such as:
  - Line & column charts for time-based trends
  - Bar charts for top-selling products
  - Pie/donut charts for category contribution
- Slicers for interactivity 

## Tools Used

- **Microsoft Excel**
  - Pivot Tables
  - Charts & Conditional Formatting
  - Basic Formulas (SUMIFS, AVERAGEIF, etc.)
  - Interactive Dashboards
